Privacy note

  • Reports are used only to investigate and fix the issue.
  • Please don’t include sensitive financial data, PINs, or personal entries. Redact anything private first.
  • If a report contains accidental personal data, we delete it once the issue is resolved.

What to expect

  • Bugs — acknowledged within a day. Fixes depend on severity and reach.
  • Feature requests — reviewed periodically. Requests that benefit more users get prioritized.
  • Security — prioritized. The subject is prefixed so it stands out.
