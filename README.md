# booksXR Website

Official landing page for the booksXR Android app.

## Files
- `index.html` — website
- `version.json` — version + changelog (edit when releasing new version)
- `booksXR-v1.1.1.apk` — current APK build

## Updating the app
1. Copy new APK to this folder (e.g. `booksXR-v1.1.2.apk`)
2. Edit `version.json` — bump `version`, update `apkFile`, add changelog entry
3. Commit + push to GitHub
4. GitHub Pages auto-deploys in ~1 min
