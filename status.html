Known Issues & Limitations

  • Note
    APK install warnings

    Android and Google Play Protect may warn about apps installed outside the Play Store. This is normal for direct APK downloads. Only install APKs from this site.

  • Minor
    Reminder timing on some devices

    On a few Android builds with strict battery optimization, reminders may fire slightly late. Fixed in booksXR v1.1.1; update to the latest version if you see this.

  • Minor
    Updates keep app data

    Installing a new APK over an existing version normally keeps your data. Uninstalling first removes it, so back up inside the app before uninstalling.

Compatibility

  • Android version: Android 8.0 (Oreo) and above recommended. Older versions may work but are not tested.
  • Installation: Enable “Install from unknown sources” for your browser once — Android remembers it after that.
  • Storage: Each APK is roughly 10–15 MB. App data grows slowly depending on how much you record.
  • Internet: Not required for apps to run. Only needed for downloads and optional cloud backups.
  • Backups: Use the in-app export/backup option before uninstalling or switching phones.
